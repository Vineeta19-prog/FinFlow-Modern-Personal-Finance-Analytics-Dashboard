# FinFlow-Modern-Personal-Finance-Analytics-Dashboard
The application acts as a real-time ledger where users can log income and expenses. Unlike static dashboards, it uses a state-driven architecture in Vanilla JavaScript—meaning whenever a user adds a transaction, the entire UI (Stat Cards, Tables, and Charts) updates instantly without a page refresh.
# FinFlow+ | Modern Finance Dashboard

FinFlow+ is a clean, interactive, and responsive frontend finance dashboard built with Vanilla JavaScript, HTML5, and CSS3. It allows users to track their financial activity, visualize spending patterns, and manage roles through a sleek "Glassmorphism" interface.

## ✨ Key Features

- **Dynamic Dashboard:** Real-time updates for Total Balance, Income, and Expenses.
- **User-Driven Entries:** Add your own transactions via an intuitive prompt system.
- **Live Search & Filter:** Instantly filter the transaction ledger by category.
- **Advanced Analytics:** A vertical bar chart visualizing both Income (Green) and Expenses (Indigo) for trend analysis.
- **RBAC (Role-Based Access Control):** - **Admin:** Full access to add and view data.
  - **Viewer:** Read-only mode where the "New Entry" functionality is hidden.
- **Multi-Currency Support:** Switch between USD ($), INR (₹), EUR (€), and GBP (£).
- **Dark Mode:** A smooth, CSS-variable-driven dark theme for a better night-time experience.
- **Responsive Design:** Fully functional across desktop and mobile screen sizes.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Custom Variables & Flexbox)
- **Logic:** Vanilla JavaScript (ES6+)
- **Icons:** [Lucide Icons](https://lucide.dev/)
- **Fonts:** Plus Jakarta Sans (via Google Fonts)
